# Network Incident Analysis Resources

This section contains reusable documentation and analysis resources developed from my network-security work.

These materials support a consistent, evidence-driven approach to investigating and documenting network incidents.

## Network Incident Analysis Report Template

A reusable report template designed to document network incidents in a structured and professional format.

The template organizes an investigation around:

- Reported symptoms
- Relevant network or system behavior
- Key findings
- Operational impact
- Incident timing
- Evidence reviewed
- Technical findings
- Working hypotheses
- Verification and next steps

[View the Network Incident Analysis Report Template](./network-incident-analysis-report-template.pdf)

## Network Incident Analysis Methodology

A reusable investigation framework for analyzing network incidents while maintaining a clear distinction between confirmed evidence and unverified hypotheses.

The methodology follows this general analysis flow:

**Expected Process → Observed Behavior → Point of Failure → Evidence vs. Inference → Operational Impact → Working Hypothesis → Verification → Report Findings**

[View the Network Incident Analysis Methodology](./network-incident-analysis-methodology.pdf)

## Purpose

These resources were developed to support repeatable network-incident analysis and technical documentation. They are included as supporting materials rather than standalone portfolio projects.
